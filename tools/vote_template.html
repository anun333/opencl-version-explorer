OpenCL 3.2 directions: what do you think?

A companion to the OpenCL Version Explorer. Independent; not from Khronos, and not a Khronos plan.
How voting works. Each direction below is a GitHub issue, and each concern is a comment on it. You vote with a GitHub reaction on that issue or comment: open it with the link and click 👍 or 👎. You need a (free) GitHub account; counts here refresh when the page reloads.
  • On a direction: 👍 = I would want this explored for a future version; 👎 = I would not.
  • On a concern: 👍 = I agree this is a real concern; 👎 = I don't think so, or I think it is wrong. If you think it is wrong, say why in a reply.
This is an informal, unweighted poll. Anyone with a GitHub account can react, one reaction per person per item, and it carries no authority. The concern text is generated from Khronos's public files by the explorer; lines it cannot judge (what is "not knowable") are shown but not voted on.
Data derived from the Khronos Group repositories OpenCL-Docs and OpenCL-Headers (see the explorer's footer and CREDITS.md). Independent; not affiliated with or endorsed by Khronos.
