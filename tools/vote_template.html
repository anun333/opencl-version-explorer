OpenCL 3.2 directions: what do you think?

A companion to the OpenCL Version Explorer. Independent; not from Khronos, and not a Khronos plan.
How voting and replies work. Each direction and each concern below is its own GitHub issue. You vote with a GitHub reaction on the issue (open it with the link and click 👍 or 👎) and you can reply there. You need a (free) GitHub account, so every vote and reply carries a real GitHub name; replies are shown here with that name. Counts and replies refresh when the page reloads.
  • On a direction: 👍 = I would want this explored for a future version; 👎 = I would not. Comment to say why.
  • On a concern: 👍 = I agree this is a real concern; 👎 = I don't think so, or I think it is wrong. If you think it is wrong, please reply and say why.
This is an informal, unweighted poll. Anyone with a GitHub account can react or reply, one reaction per person per item, and it carries no authority. Replies are shown as plain text and shortened; the full discussion is on GitHub. Abusive replies can be hidden by the owner without being deleted. The concern text is generated from Khronos's public files by the explorer; lines it cannot judge (what is "not knowable") are shown but not voted on.
Data derived from the Khronos Group repositories OpenCL-Docs and OpenCL-Headers (see the explorer's footer and CREDITS.md). Independent; not affiliated with or endorsed by Khronos.
